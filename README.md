# tashopto

Avalonia desktop replacement for karat ОПТО (ТашТЭС/ТашГРЭС): fuel accounting, shifts, and electricity generation.

## Запуск приложения

```bash
dotnet run --project Opto/Opto.csproj
```

## База данных

База данных SQLite создаётся автоматически при первом запуске:
- **Путь:** `%LOCALAPPDATA%\Opto\opto.db` (обычно `C:\Users\<username>\AppData\Local\Opto\opto.db`)

📖 **Подробное описание структуры БД:** см. [DATABASE.md](DATABASE.md)

### Что хранится в БД

База данных содержит **2 модуля**:

1. **Wyrabotka** (Выработка электроэнергии) - 4 таблицы
   - Показания счётчиков генерации по блокам
   - Показания трансформаторов собственных нужд
   - Результаты расчётов за сутки и месяц

2. **Baxta** (Ежедневный расчёт по вахтам) - 6 таблиц
   - Показания счётчиков по 4 временным точкам (0:00, 8:00, 16:00, 24:00)
   - Теплотехнические параметры (температуры, давления, O2) по 3 сменам
   - Коэффициенты для расчёта расхода топлива
   - Параметры электростанции и режимные добавки
   - Результаты расчётов

Все данные **привязаны к конкретной дате**. Каждая дата независима.

### Очистка базы данных

Чтобы полностью очистить базу данных (удалить все данные):

**Вариант 1:** Запустите скрипт
```bash
clear-database.bat
```

**Вариант 2:** Вручную через PowerShell
```powershell
Remove-Item "$env:LOCALAPPDATA\Opto\opto.db" -Force
```

**Вариант 3:** Просто удалите файл `C:\Users\<ваше_имя>\AppData\Local\Opto\opto.db`

После удаления БД при следующем запуске приложения будет создана новая пустая база данных.
